# ASTM G32 Cavitation Test Execution Plan (Track 1 FKM)

## 1. Test Overview & Objectives
This test protocol evaluates the cavitation erosion resistance of Track 1 micro-filled FKM specimens using an ultrasonic vibratory apparatus in accordance with ASTM G32 (Indirect Method).

## 2. Apparatus & Parameters
* **Ultrasonic Generator:** 20.0 kHz +/- 0.2 kHz
* **Acoustic Horn:** Titanium Ti-6Al-4V exponential sonotrode
* **Vibration Amplitude:** 50 um peak-to-peak (calibrated via Laser Doppler Vibrometer)
* **Stand-Off Gap:** 0.50 mm +/- 0.02 mm between horn tip and stationary sample
* **Test Fluid:** AC-FLUID-OPT-500ML maintained at 40.0°C +/- 0.5°C
* **Total Exposure Time:** 240 minutes (8 x 30-minute cycles)

## 3. Step-by-Step Execution Sequence
1. **Pre-Test Preparation:**
   * Clean circular disc specimens (15.9 mm diameter, 2.0 mm thickness) in Isopropyl Alcohol (IPA) ultrasonic bath for 10 minutes.
   * Vacuum dry at 60°C (< 10 mbar) for 2 hours; cool in desiccator.
   * Record initial mass (m0) on analytical balance (+/- 0.01 mg precision).
2. **Interval Testing (30, 60, 90, 120, 150, 180, 210, 240 min):**
   * Mount specimen in Teflon holder; verify 0.50 mm stand-off clearance.
   * Engage fluid bath circulation (40.0°C) and start 20 kHz horn vibration.
   * At each 30-minute mark, stop horn, remove sample, wash in IPA, vacuum dry for 20 minutes, and weigh (mi).
   * Calculate cumulative mass loss: Delta_m = m0 - mi.
3. **Acceptance Criteria:**
   * **Cumulative Mass Loss at 240 min:** <= 4.80 mg (Erosion rate <= 1.20 mg/hr).
   * **Surface Topography:** Maximum pit depth (Rv) <= 8.0 um via 3D optical profilometry.
